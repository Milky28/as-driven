# Control-guidance changes: 0.5.49 to 0.5.50

9 changed control field(s) across 9 car(s).

Each car below now explicitly says **Clutch required** when pulling away in its
real-car baseline. Previously this was **Not established**. These are the
reviewed H-pattern standing-start corrections; they do not change running-shift
guidance or add new car records.

**The value is derived, not sourced.** An H-pattern gate is a driver-shifted
gearbox, and a driver-shifted gearbox has to be declutched to pull away from
rest, whatever its construction. All five registered H-pattern archetypes carry
`required`, and of the 96 curated H-pattern records the 87 that had already
established the field all said `required`, with no dissenting value anywhere in
the dataset. Unlike the blip derivations this one does not rest on
`gearbox_type`, so four cars with an unknown construction were settled too. See
`docs/data-model.md`.

Every one of these nine had also been driven in a simulator that demanded the
clutch to move off. That corroborates the value without establishing it, which is
why no drive is cited for it: a drive settles what the simulator does, not what
the real car required.

Generated by `release-control-changes` against tag `v0.21.3`. Each entry names
only the sources whose provenance claim actually covers the changed field, so a
field with no real-car source says so instead of listing the record's other
evidence.
